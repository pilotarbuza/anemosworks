# Загрузка AnemosWorks

[ [English](DOWNLOADS.md) | Русский ]

**Публичный Windows EXE-установщик пока не выпущен.**

Работающее CAD-ядро версии 1.3.0 и будущая версия настольного приложения — разные этапы продукта.
Архив исходных кодов GitHub не является установщиком и не содержит коммерческого CAD-ядра.

После выпуска дистрибутивы будут доступны исключительно в разделе
**[GitHub Releases](https://github.com/pilotarbuza/anemosworks/releases)**.
Каждый релиз будет содержать подписанный установщик, контрольную сумму SHA-256, системные требования,
список изменений и инструкцию по установке.

Первая версия ориентирована на Windows и поддерживаемые выпуски SOLIDWORKS / Autodesk Fusion.
Точная матрица совместимости будет опубликована вместе с установщиком.

Даты выпуска, стоимость и условия подписки пока не объявлены. Оплата не принимается.
Для получения уведомлений включите **Watch -> Custom -> Releases** на GitHub.
