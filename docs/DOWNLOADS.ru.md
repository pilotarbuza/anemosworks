# Загрузка

[ [English](DOWNLOADS.md) | Русский ]

Публичного установщика для Windows пока нет.

CAD-ядро версии 1.3.0 уже работает, а настольное приложение выйдет позже, это отдельный этап. Архив исходников, который генерирует GitHub, установщиком не является, и коммерческого ядра в нем нет.

Установщики будут выкладываться только в [GitHub Releases](https://github.com/pilotarbuza/anemosworks/releases). В каждом релизе будут подписанный установщик, контрольная сумма SHA-256, системные требования, список изменений и инструкция по установке.

Первая версия рассчитана на Windows и поддерживаемые версии SOLIDWORKS или Autodesk Fusion. Точный список совместимости опубликую вместе с установщиком.

Даты выхода, цены и условия подписки пока не объявлены, оплата не принимается. Чтобы узнать о релизе, включите на GitHub **Watch → Custom → Releases**.
