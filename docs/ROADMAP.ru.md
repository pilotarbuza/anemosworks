# План разработки

[ [English](ROADMAP.md) | Русский ]

Здесь описано, где проект находится сейчас. Сроков выхода функций этот план не обещает.

## Уже сделано

- Общее CAD-ядро и MCP-сервер для SOLIDWORKS и Autodesk Fusion.
- Параметрическое моделирование, поддерживаемые сборочные операции и экспорт.
- Проверки геометрии и откат, если эскиз во Fusion создать не удалось.
- Сроки ожидания команд, отмена команд в очереди и защита от повторного выполнения.
- Проверка версии дополнения Fusion и резервная копия перед каждым обновлением.

## Первая версия приложения (в планах)

- Установщик для Windows, который сам проверяет зависимости.
- Свой интерфейс для задач, истории и чата.
- Автоматический поиск запущенных CAD-сессий.
- Привязка задачи к открытому документу, без ручного выбора CAD при запуске.
- Мастер подключения MCP-клиентов.
- Вход к ИИ-провайдерам через протоколы, которые они сами разрешают.
- Подписка AnemosWorks на аккаунт, управление устройствами и обновления внутри приложения.

## Дальше

- Готовые инженерные сценарии, которые можно запускать повторно.
- Больше проверок на реальных сборках пользователей.
- Больше версий CAD и ИИ-клиентов.
- Адаптеры для других CAD-систем, каждый после отдельной реализации и тестов.
