# План разработки

Статусы отражают текущее состояние. Это не обязательство выпустить функцию к определённой дате.

## Реализованная основа

- CAD-ядро и MCP-сервер для SOLIDWORKS и Fusion.
- Параметрическое моделирование, поддерживаемые сборочные операции и экспорт.
- Проверки результата, откат неудачного создания эскиза Fusion.
- Срок действия команд, отмена ожидающих запросов и защита от повторного выполнения.
- Проверка версий дополнения Fusion и резервные копии при обновлении.

## Первый настольный выпуск — запланировано

- Windows EXE-установщик и проверка зависимостей.
- Собственный интерфейс задач и чата.
- Автоматическое обнаружение поддерживаемых CAD-сессий.
- Привязка задачи к конкретному документу без обязательного выбора CAD при запуске.
- Мастер подключения совместимых MCP-клиентов.
- Подключение AI-провайдеров разрешёнными ими способами.
- Подписка AnemosWorks на аккаунт, управление устройствами и обновления приложения.
