# Загрузка AnemosWorks

**Публичный Windows EXE-установщик пока не выпущен.**

Работающее CAD-ядро 1.3.0 и будущая версия настольного приложения — разные этапы продукта.
Архив исходников GitHub не является установщиком и не содержит коммерческого CAD-ядра.

После выпуска файлы будут доступны только в
[Releases этого репозитория](https://github.com/pilotarbuza/anemosworks/releases).
Каждый релиз будет содержать установщик, контрольную сумму SHA-256, требования к системе,
список изменений и инструкцию по установке.

Ориентир первой версии — Windows и поддерживаемые установки SOLIDWORKS / Autodesk Fusion.
Точная матрица совместимости будет опубликована вместе с установщиком.

Даты выпуска, стоимость и условия подписки пока не объявлены. Оплата не принимается.
Для уведомлений о публикациях можно включить **Watch → Custom → Releases** на GitHub.
