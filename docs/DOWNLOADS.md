There is no public Windows installer yet.

The CAD engine (v1.3.0) already works; the standalone desktop app is a separate, later milestone. The source archive that GitHub generates is not an installer and does not include the engine.

Installers will be published only on [GitHub Releases](https://github.com/pilotarbuza/anemosworks/releases). Each release will include a signed installer, a SHA-256 checksum, system requirements, a changelog and installation steps.

The first release is for Windows with a supported version of SOLIDWORKS or Autodesk Fusion. The exact compatibility list will be published together with the installer.

Release dates, prices and subscription terms have not been announced, and no payments are accepted. To hear about a release, set **Watch → Custom → Releases** on GitHub.
