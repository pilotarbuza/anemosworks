# AnemosWorks Downloads

[ English | [Русский](DOWNLOADS.ru.md) ]

**A public Windows EXE installer has not been released yet.**

The working CAD engine (v1.3.0) and the upcoming standalone desktop application represent separate milestones.
The GitHub source code archive is not an installer and does not contain the proprietary CAD engine.

Once released, distribution packages will be available exclusively through
**[GitHub Releases](https://github.com/pilotarbuza/anemosworks/releases)**.
Each release will contain a signed installer, SHA-256 checksum, minimum system requirements,
changelog, and installation instructions.

The initial release targets Windows with supported installations of SOLIDWORKS and Autodesk Fusion.
The exact platform compatibility matrix will be published alongside the installer.

Release dates, pricing tiers, and subscription terms have not been announced. Payments are not currently accepted.
To receive release notifications, configure **Watch -> Custom -> Releases** on GitHub.
